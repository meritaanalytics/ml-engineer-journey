# Data

The raw data is **not** included in this repository (Zindi's data terms; also good practice).

## How to get it
1. Create a free account at <https://zindi.africa>.
2. Open **Financial Inclusion in Africa**: <https://zindi.africa/competitions/financial-inclusion-in-africa/data>
3. Join the competition, then download:
   - `Train.csv`
   - `Test.csv` (only needed for the optional leaderboard submission)
   - `VariableDefinitions.csv`
4. Save them in `data/raw/` (this folder is git-ignored).
